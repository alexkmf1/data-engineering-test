## Local Development Requirements

The following software is required to run the project locally:

- Python 3.14
- Java JDK 17
- PySpark 4.2.0

### Java

PySpark requires Java to run. This project uses Java JDK 17.

On Windows, Java 17 can be installed with:

```powershell
winget install EclipseAdoptium.Temurin.17.JDK
